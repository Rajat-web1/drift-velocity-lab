# DriftLab: E×B Drift in 3D

An interactive, single-page 3D simulation of a positive charge moving in crossed electric and magnetic fields.

**Live demo:** https://rajat-web1.github.io/drift-velocity-lab/

## What's inside
- **Home:** Overview and the drift formula, v_d = E / B
- **Learn:** Four steps from E-only motion to the drift velocity
- **3D Lab:** Adjust E, B and launch speed, change camera views, and compare theory with measurement
- **Quiz:** Four questions with instant feedback

## How to use
Drag the scene to rotate it. Use the sliders and buttons in the Lab to explore.

- `index.html`: the whole site (HTML, CSS and JavaScript in one file)
